# SmartPRS by Ametecs — Application (Laravel 11)

Greenfield Laravel 11 build of the SmartPRS HRM / Payroll / workforce-compliance platform.
Built fresh per the **locked decision** in `../CONTEXT-HANDOFF.md`; the purchased
`ametecs_payroll` codebase is a **reference library only** (see `../SmartPRS-Harvest-Reference.md`).

> Stack: **Laravel 11 · PHP 8.3 · MySQL 8 · Redis · Blade + Livewire 3 · Spatie Permission · Sanctum**

## What's in this scaffold (Phase 0 foundation)
This folder holds the **SmartPRS-specific** files that sit on top of a fresh Laravel 11 install:

```
composer.json                         Laravel 11 + harvested deps (Spatie, Sanctum, Livewire, ZKTeco, Excel, dompdf)
.env.example                          Local config (Asia/Kolkata, Redis, ZKTeco)

database/migrations/                  companies, users.company_id, employees
database/seeders/                     RolePermissionSeeder (5 roles), DemoCompanySeeder, DatabaseSeeder
resources/css/smartprs-theme.css      Locked design tokens (navy #0c1929 / orange #f97316)
```

## Bootstrap (Windows / Laragon — run inside `smartprs/`)
A fresh Laravel skeleton (the `artisan` file, `bootstrap/`, `public/`, framework config, etc.) is
generated by Composer; this folder then supplies the SmartPRS files above. Two ways to assemble:

**Option A — overlay onto a fresh Laravel 11 app (recommended):**
```powershell
# 1. Create a fresh Laravel 11 app in a temp dir
composer create-project laravel/laravel:^11.0 _fresh
# 2. Copy the framework skeleton it generated into this folder (without overwriting our files)
#    (artisan, bootstrap/, public/, the base config/, tests/, etc.)
# 3. Then, in this folder:
composer install
npm install
cp .env.example .env
php artisan key:generate

# install the harvested packages' service providers / config
php artisan vendor:publish --provider="Spatie\Permission\PermissionServiceProvider"

# create the `smartprs` MySQL database, then:
php artisan migrate --seed
npm run dev
php artisan serve            # http://localhost:8000
# separate terminals:
php artisan queue:work       # device sync, payroll, reminders
php artisan schedule:work
```

**Option B — let me (the assistant) generate the remaining skeleton files** in a follow-up step,
so this folder becomes a complete `composer install`-ready Laravel root.

## Multi-tenancy model
Single-DB tenant scoping (TDD §3). Every tenant-owned model uses `BelongsToCompany`, which
(1) adds `CompanyScope` so reads are isolated to the user's `company_id`, and (2) auto-fills
`company_id` on create. `super_admin` bypasses the scope for SaaS cross-tenant operation.
On-prem deployments run single-tenant; the scope is a harmless safeguard.

## Conventions (locked)
- Money: **decimal columns, never float**. Audit every write via `spatie/laravel-activitylog`.
- Format with **Pint** (PSR-12), analyse with **Larastan/PHPStan**, test with **Pest** before commit.
- Branching: `main` (prod) ← `develop` ← `feature/<module>` via reviewed PR.
